Guide to repo.

Corpus samples folder: Contains the samples of the corpus throughout the corpus construction process. /n
Hansard folder: Contains the Two JSON files appended to the corpus and a sample of the original corpus (2016). /n
Project Outputs: A catalogue of key decisions and key files holding information which were used to make key decisions. These are broken down into Analysis artefacts, Corpus Construction artefacts, and LDA outputs. /n
Testing folder: Contains scripts for different aspects of testing the data. Broken down into Chairs analysis, K Sampling, and python scripts for testing. /n
Main: the data pipeline for the analysis for this project. It follows a chronology of the analysis. Additional scripts (such as 12b, 13c) have been added to highlight small changes to scripts which were made for particular parts of the analysis.
