Guide to repo.

Corpus samples folder: Contains the samples of the corpus throughout the corpus construction process.
Hansard folder: Contains the Two JSON files appended to the corpus and a sample of the original corpus (2016).
Project Outputs: A catalogue of key decisions and key files holding information which were used to make key decisions. These are broken down into Analysis artefacts, Corpus Construction artefacts, and LDA outputs.
Testing folder: Contains scripts for different aspects of testing the data. Broken down into Chairs analysis, K Sampling, and python scripts for testing. 
Main: the data pipeline for the analysis for this project. It follows a chronology of the analysis. Additional scripts (such as 12b, 13c) have been added to highlight small changes to scripts which were made for particular parts of the analysis.
